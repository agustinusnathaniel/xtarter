<p class="xt-eyebrow xt-section-label">03 · Quick start</p>

<h2 class="xt-section-title">Quick Start</h2>

Scaffold a new project in one command:

```bash
# Scaffold a new project
pnpm create xtarter-app

# Follow the interactive prompts to pick your template
# ?? Which template?
#   - Next.js + Chakra UI
#   - Next.js + Tailwind
#   - Vite + React + Chakra
#   - Vite + React + Tailwind
#   - Vite + React + Hero UI
```
