<Aside type="caution" title="Current focus: Vite + React + TypeScript">
  Detection covers a wide range of frameworks. Task coverage is deepest for Vite, React, and TypeScript projects. Other stacks such as Vue, Svelte, Solid, Node CLIs, and Bun work but stay experimental: fewer tasks, less maturity. Contributions to expand coverage are welcome.
</Aside>
