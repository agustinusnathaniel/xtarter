<div class="xt-section"><SectionHead index="01" id="how-it-works" title="How a run works" lead="Every run follows the same five steps." />
<ol class="xt-pipeline">
  <li class="xt-pipe"><span class="xt-pipe-name">Detect</span><p class="xt-pipe-desc">Profile the project: framework, bundler, package manager, existing configs.</p></li>
  <li class="xt-pipe"><span class="xt-pipe-name">Resolve</span><p class="xt-pipe-desc">Map the profile to the conformance tasks that apply.</p></li>
  <li class="xt-pipe"><span class="xt-pipe-name">Check</span><p class="xt-pipe-desc">Compare each file against the standard: new, patch, skip, or conflict.</p></li>
  <li class="xt-pipe"><span class="xt-pipe-name">Plan</span><p class="xt-pipe-desc">Review the plan before anything is written.</p></li>
  <li class="xt-pipe"><span class="xt-pipe-name">Apply</span><p class="xt-pipe-desc">Back up originals, then merge or rewrite configs.</p></li>
</ol>
</div>

<Aside type="caution" title="Current focus: Vite + React + TypeScript">
  Task coverage is deepest for Vite, React, and TypeScript projects. Other stacks such as Vue, Svelte, Solid, Node CLIs, and Bun work but stay experimental with fewer tasks. Contributions to expand coverage are welcome.
</Aside>
