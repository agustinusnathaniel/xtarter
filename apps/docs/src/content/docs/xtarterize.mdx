<h2 class="xt-section-title">The pipeline</h2>

<p class="xt-section-lead">Every run follows the same five steps, from reading your project to applying changes with backups in place.</p>

<ol class="xt-pipeline">
  <li class="xt-pipe">
    <span class="xt-pipe-name">Detect</span>
    <p class="xt-pipe-desc">Profile your project: framework, bundler, package manager, existing configs.</p>
  </li>
  <li class="xt-pipe">
    <span class="xt-pipe-name">Resolve</span>
    <p class="xt-pipe-desc">Map that profile to the conformance tasks that apply to your stack.</p>
  </li>
  <li class="xt-pipe">
    <span class="xt-pipe-name">Check</span>
    <p class="xt-pipe-desc">Compare each file against the standard: new, patch, skip, or conflict.</p>
  </li>
  <li class="xt-pipe">
    <span class="xt-pipe-name">Plan</span>
    <p class="xt-pipe-desc">Review the conformance plan before anything is written.</p>
  </li>
  <li class="xt-pipe">
    <span class="xt-pipe-name">Apply</span>
    <p class="xt-pipe-desc">Back up originals, then merge or rewrite configs.</p>
  </li>
</ol>

<Aside type="caution" title="Current focus: Vite + React + TypeScript">
  The CLI detects a wide range of frameworks, but the deepest task coverage is for **Vite**, **React**, and **TypeScript** projects. Support for other stacks (Vue, Svelte, Solid, Node CLI, Bun, etc.) works but is **experimental** - tasks may be fewer or less mature. Contributions to expand coverage are welcome.
</Aside>
