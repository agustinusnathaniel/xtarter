    title="One run, five decisions."
    lead="xtarterize turns an unfamiliar repository into a sequence you can inspect before the executor touches project files."
  />
  <ol class="xt-pipeline">
    <li class="xt-pipe">
      <span class="xt-pipe-name">Detect</span>
      <p class="xt-pipe-desc">Profile the project: framework, bundler, package manager, monorepo status, and existing configs.</p>
    </li>
    <li class="xt-pipe">
      <span class="xt-pipe-name">Resolve</span>
      <p class="xt-pipe-desc">Map that profile to the conformance tasks that apply here.</p>
    </li>
    <li class="xt-pipe">
      <span class="xt-pipe-name">Check</span>
      <p class="xt-pipe-desc">Classify each task as new, patch, skip, or conflict.</p>
    </li>
    <li class="xt-pipe">
      <span class="xt-pipe-name">Plan</span>
      <p class="xt-pipe-desc">Render the proposed changes and the next action. A dry run does not create backups.</p>
    </li>
    <li class="xt-pipe">
      <span class="xt-pipe-name">Apply</span>
      <p class="xt-pipe-desc">Back up modified files, install declared dependencies, then merge or rewrite the selected configs.</p>
    </li>
  </ol>
</div>

:::caution[Coverage follows the stack]
Coverage is deepest for Vite, React, and TypeScript. Other JavaScript and TypeScript stacks can use the CLI, but task coverage may be narrower or experimental.
:::
