Writes or merges `.vscode/settings.json` and `.vscode/extensions.json`.

## Settings

- Biome as the formatter for TS, JS, JSON, and JSONC; format on save enabled; format on paste disabled
- Biome fix and organize imports as explicit code actions on save
- Non-relative import module specifiers (`@/` paths); update imports on file move for TS and JS

Detected tools add settings:

| Detected | Added |
| --- | --- |
| Monorepo | `typescript.tsdk` from the workspace; `search.exclude` for `node_modules`, `.turbo`, `dist` |
| Vite | `files.associations` maps `.css` to Tailwind CSS |
| Vue | `vue.server.hybridMode`; Vue formatter |
| React Native | `typescript.tsserver.watchOptions` for fs events |
| Next.js | `typescript.tsdk`; Emmet JSX languages |
| TanStack Router | `files.exclude` hides `routeTree.gen.ts` |
| Tailwind CSS | CVA/CN class regex patterns for IntelliSense |
| TypeScript | `typescript.disableAutomaticTypeAcquisition`; `typescript.enablePromptUseWorkspaceTsdk` |

## Extensions

Recommends `biomejs.biome` and `ms-vscode.vscode-typescript-next`, plus framework-specific extensions for Tailwind CSS, Vue, or React Native. Existing recommendations are kept and merged, never removed.
