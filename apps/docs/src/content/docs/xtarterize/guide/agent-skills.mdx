The xtarterize skill teaches AI tools how to drive the CLI: commands, flags, `--json` output shapes, task statuses, and conformance workflows.

## Install

```bash
npx skills add agustinusnathaniel/xtarter
```

The skill activates when you ask about conformance, linting, CI, or any xtarterize task.
