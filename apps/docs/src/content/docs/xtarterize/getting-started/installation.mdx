## Prerequisites

- Node.js 24 or later
- A JavaScript or TypeScript project, or a directory for a new one
- A `package.json` with a `name` field and an initialized Git repository (preflight checks validate both before making changes)

## Run without installing

Run it without installing anything globally:

<AllPackageManagers type="exec" pkg="xtarterize@latest" args="init" />

## Verify it works

<AllPackageManagers type="exec" pkg="xtarterize@latest" args="--version" />

<AllPackageManagers type="exec" pkg="xtarterize@latest" args="--help" />
