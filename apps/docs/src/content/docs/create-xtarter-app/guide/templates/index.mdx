Every template ships the same production baseline: Biome, strict TypeScript, GitHub Actions CI, VS Code settings, and agent skills.

| ID | Stack |
| --- | --- |
| `next-chakra` | Next.js 16, Chakra UI v3, Turborepo, TypeScript, Playwright |
| `next-tailwind` | Next.js 16, Tailwind CSS v4, TypeScript, Playwright |
| `vite-chakra` | Vite+ (Vite 8), React 19, Chakra UI v3, TanStack Router, TanStack Query, Vitest |
| `vite-tailwind` | Vite+ (Vite 8), React 19, Tailwind CSS v4, TanStack Router, TanStack Query, Vitest |
| `vite-hero` | Vite+ (Vite 8), React 19, Hero UI, TanStack Router, Vitest |

Scaffold any of them:

<AllPackageManagers type="create" pkg="xtarter-app@latest" args="my-app --template vite-tailwind" />

Inspect a template before scaffolding with the `preview` subcommand — it prints the template's name, description, repository, branch, and features.
