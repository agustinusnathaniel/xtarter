## Install

<AllPackageManagers type="dlx" pkg="skills@latest" args="add agustinusnathaniel/xtarter" />

The skill covers the scaffold and `preview` commands, all flags, and the five template IDs (`next-chakra`, `next-tailwind`, `vite-chakra`, `vite-tailwind`, `vite-hero`).
