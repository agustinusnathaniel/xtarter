Install the create-xtarter-app skill in a compatible AI tool to provide
guidance for scaffolding, template selection, and project creation.

When installed, your AI assistant knows how to pick the right template from your stack description, use proper flags, and follow best practices.

## Install

```bash
npx skills add agustinusnathaniel/xtarter
```

## What the skill teaches

| Area | What the agent gets |
| --- | --- |
| Commands | Scaffold and `preview` commands with their flags (`--template`, `--pm`, `--git`/`--no-git`, `--clean`, `--force`, `--ref`, `--yes`, `--quiet`, `--json`, `--color`) |
| Templates | The 5 valid IDs (`next-chakra`, `next-tailwind`, `vite-chakra`, `vite-tailwind`, `vite-hero`) and a decision table mapping stack descriptions to template IDs |
| Workflows | Scaffolding, previewing, and CI usage, plus anti-patterns to avoid |
| Typical asks | "Next.js with Tailwind" → `--template next-tailwind`; "Vite SPA with Chakra" → `--template vite-chakra`; "What templates are available?" → the 5 valid IDs; "Preview vite-tailwind" → `preview vite-tailwind` |

The skill activates when you ask about creating a project or mention a template, and matches your stack description to the correct template ID so you don't need to remember template names.
